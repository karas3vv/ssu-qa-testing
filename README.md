# Автотесты «Гипермаркета ДОМ»

В проекте 10 UI-тестов на Python, pytest и Playwright. Для входа по паролю есть одна проверка успешного входа и пять проверок ошибок. Ещё четыре теста покрывают поиск по артикулу, карточку товара, корзину и оформление самовывоза.

## Запуск после клонирования

Понадобятся Python 3.10+, Node.js с npm и Java для Allure. Запускайте команды в Bash из папки проекта.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
npm ci
```

### Учебный стенд

```bash
TARGET=demo HEADED=1 .venv/bin/python -m pytest -q
```

Тестовые данные подставляются автоматически. Сквозной сценарий создаёт локальный заказ, проверяет его номер, состав и сумму. Ожидаемый результат — **9 прошли, 1 пропущен**. Пропущенная проверка относится к гостевой корзине реального магазина.

### Реальный сайт

```bash
TARGET=store HEADED=1 PROMPT_LOGIN=1 .venv/bin/python -m pytest -qs --alluredir=store-results
```

Понадобится тестовый аккаунт магазина с входом по паролю. Введите в обычном терминале логин аккаунта и пароль. Для проверенного аккаунта логин — номер телефона. Если магазин принимает email для вашего аккаунта, введите его. Ввод скрыт, данные аккаунта в репозитории отсутствуют. Вход с одноразовым кодом из звонка исключён, поскольку для него нужен доступ к телефону.

Перед запуском освободите корзину тестового аккаунта. Тест добавляет выбранный товар и при повторном запуске может удалить его точные дубли. Сквозной сценарий проверяет сумму на форме самовывоза и останавливается перед отправкой заказа.

Если магазин покажет CAPTCHA, пройдите её в открытом браузере. Поиск на реальном сайте зависит от загрузки виджета Diginetica.

## Как открыть результаты

После завершения pytest соберите отчёт в той же папке проекта.

- Для запуска без `--alluredir` выполните `npm run report` и откройте `allure-report/index.html`.
- Для запуска с `--alluredir=store-results` выполните команду ниже и откройте `store-report/index.html`.

```bash
./node_modules/.bin/allure generate store-results --clean --single-file -o store-report
```

В разделе **Suites** видны статусы, шаги и вложения. При сбое тест прикладывает снимок страницы со скрытыми полями и текстом, если страница доступна.

При новом запуске pytest очищает выбранный каталог результатов. Чтобы сохранить результаты нескольких прогонов, задавайте разные пути в `--alluredir` и указывайте нужный путь при генерации отчёта.
