# Автотесты «Гипермаркета ДОМ»

Тесты на Python, pytest и Playwright. Шесть тестов проверяют вход по логину и паролю. Ещё четыре покрывают поиск по артикулу, карточку товара, корзину и оформление самовывоза.

## Запуск после клонирования

Понадобятся Python 3.10+, Node.js с npm и Java для Allure. Запускайте команды из папки проекта.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
npm ci
```

### Учебный стенд

```bash
TARGET=demo HEADED=1 .venv/bin/python -m pytest -q
```

Тестовые данные подставляются автоматически. Сквозной сценарий создаёт локальный заказ, проверяет его номер, состав и сумму. Ожидаемый результат — **9 прошли, 1 пропущен**. Пропущенная проверка относится к гостевой корзине реального магазина.

### Реальный сайт

```bash
TARGET=store HEADED=1 PROMPT_LOGIN=1 .venv/bin/python -m pytest -qs --alluredir=store-results
```

Понадобится аккаунт магазина с входом по паролю. Введите в терминале номер телефона (на данном сайте почему-то вместо почты требуют номер телефона), затем пароль. Если появится CAPTCHA, пройдите её в браузере. Для сквозного сценария начните с пустой корзины. Проверка заканчивается на форме самовывоза до отправки заказа. Вход по одноразовому коду из звонка требует доступа к номеру и исключён из набора.

## Как открыть результаты

После завершения pytest соберите отчёт в той же папке проекта.

- Для запуска без `--alluredir` выполните `npm run report` и откройте `allure-report/index.html`.
- Для запуска с `--alluredir=store-results` выполните команду ниже и откройте `store-report/index.html`.

```bash
./node_modules/.bin/allure generate store-results --clean --single-file -o store-report
```

Откройте `index.html` в браузере. В разделе **Suites** выберите тест, чтобы посмотреть его статус и шаги. Если вы указали другой каталог в `--alluredir`, подставьте его вместо `store-results`.
